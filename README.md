# VILABULB

VILABULB is a short-video social platform. The website is being built first; a mobile app can follow later.

## Run locally
1. Install Node.js 20 or newer.
2. Run `npm install`.
3. Run `npm run dev`.
4. Open http://localhost:3000.

## Current starter features
- Responsive TikTok-inspired video feed layout.
- Demo vertical videos with next/previous controls.
- Local demo like and follow interactions.
- Upload prompt placeholder.

## Next development steps
- Connect a dedicated Supabase project.
- Add authentication and creator profiles.
- Add secure video uploads and storage.
- Store likes, comments, follows and views.
- Build notifications, messaging, search and moderation tools.

Demo media uses sample public video URLs and must be replaced with approved creator uploads before production. This starter is not yet a production social network.
